A Telegram chat client for Neovim

Read, send, and manage your Telegram messages directly inside Neovim. Powered by TDLib with real-time sync via WebSocket.

Get Started
lazy.nvim 
{
  "ChuYanLon/telegram.nvim",
  build = "npm i",
  keys = { { "<leader>tt", "<cmd>Tg<Cr>" } },
  opts = {},
}
Everything you need

Fully Featured

telegram.nvim comes with everything you need to chat on Telegram from within Neovim.

Messaging

Real-time send, edit, delete, forward, and reply with markdown formatting via WebSocket.

Media

Photo, video, sticker, file previews with HD download. Read receipts, view counts, typing indicators.

Chat Management

Groups, channels, DMs. Member management, permissions editor, invite links, pin & react.

Neovim Native

Configurable panel, floating input with treesitter, cursor persistence, statusline integration.

Auth & Sync

Phone → code → 2FA flow, session persistence, multi-device sync, proxy support.

GitHub

Create & merge PRs, browse issues from Neovim via :TgPr and :TgIssue.

How it works

Start chatting in three steps

Backend powered by TDLib + TypeScript, frontend in pure Lua.

Step 1

Install & Run

Add to lazy.nvim, run :Tg. The backend boots on port 8080 and connects to Telegram via TDLib.

Step 2

Authenticate

Enter phone number, verification code, and 2FA password if needed. Session persists across restarts.

Step 3

Chat

Browse groups, channels, DMs with fuzzy search. Real-time messages flow through the WebSocket bridge.
