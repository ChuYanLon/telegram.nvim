telegram.nvim

A full-featured Telegram chat client that runs inside Neovim.

GitHub Installation Documentation Telegram

Features

💬

Messaging

Real-time send, edit, delete, forward, and reply with markdown formatting via WebSocket.

📁

Media

Photo, video, sticker, file previews with HD download. Read receipts, view counts, typing indicators.

👥

Chat Management

Groups, channels, DMs. Member management, permissions editor, invite links, pin & react.

🎨

Neovim Native

Configurable panel, floating input editor with treesitter, cursor persistence, statusline integration.

🔐

Auth & Sync

Phone → code → 2FA flow, session persistence, multi-device sync, proxy support.

⚡

GitHub

Create & merge PRs, browse issues directly from Neovim via :TgPr and :TgIssue.

Quick Start

lazy.nvim 
{
  "ChuYanLon/telegram.nvim",
  build = "npm i",
  event = "VeryLazy",
  keys = {
    { "<leader>tt", "<cmd>Tg<Cr>", desc = "Toggle Telegram" },
  },
  opts = {},
}

How It Works

Step 1

Start

Run :Tg in Neovim. The TypeScript backend boots on port 8080 and connects to Telegram via TDLib.

Step 2

Authenticate

Enter phone number, verification code, and 2FA password if needed. Session persists across restarts.

Step 3

Chat

Browse groups, channels, DMs with fuzzy search. Real-time messages flow through an integrated WebSocket bridge.

Requirements

Neovim ≥ 0.9 Node.js ≥ 18 libtdjson ≥ 1.8.64 curl snacks.nvim (optional) ImageMagick (optional) gh CLI (optional)
